# Рабочая память Testing

## 1. Роль и область ответственности
Testing отвечает за тестовые модели, Stanford PLY, аналитические фигуры, синтетические плотности, unit/integration tests, benchmarking и геометрические метрики. Контролировать сетку, изоуровень, качество поверхности, производительность и ошибку относительно эталона. Не менять алгоритмы ради прохождения тестов.

## 2. Текущее состояние
Статический аудит завершён. Сборки, приложения и тесты не запускались; текущее прохождение не установлено. Исходники, тесты и CMake не менялись. Пользователь разрешил создание только собственного файла памяти.

## 3. Проверенные факты о проекте
- `AGENTS.md`: C++20, CMake/Eigen, собственные DC/emilk, MC, опциональные CGAL/ParaView и VTK для PLY. Запуски сборок, приложений и тестов запрещены до нового разрешения пользователя. Удалённые результаты не восстанавливать.
- `CMakeLists.txt`: шесть тестовых программ из `tests/dual_contouring.cpp`, `tests/extraction_methods.cpp`, `tests/cgal_extraction.cpp`, `tests/architecture.cpp`, `tests/optimization.cpp`, `tests/application.cpp`. Вместе с legacy-примерами статически насчитано 24 регистрации CTest без CGAL, 27 с CGAL; это не результат запуска ctest.
- `CMakePresets.json`: release/debug используют локальный MSYS2 UCRT64, включают VTK, ParaView, CGAL и BUILD_TESTING.
- `tests/dual_contouring.cpp`: сфера на анизотропной сетке, ошибка вершин <0.03, замкнутость и ориентация рёбер, характеристика Эйлера 2; плоскость, пустое поле, валидация и OBJ.
- `tests/extraction_methods.cpp`: все 256 конфигураций MC, корни рёбер, связность и ориентация плоскости, ненулевой изоуровень, QEF/emilk, масштабирование поля, градиенты и OBJ.
- `tests/optimization.cpp`: seed 4261; 192 сравнения двух собственных DC плюс два случая плоскости. Связность точно, координаты с допуском 1e-8*max(1,norm(reference)). Это контроль регрессии, не независимый геометрический эталон.
- `tests/architecture.cpp`: реконструкция линейного поля, индексация VF, знак плотности, defaults, API и условная проверка ParaView. `tests/cgal_extraction.cpp`: плоскость, градиенты, ориентация, валидация и отключённый backend.
- `tests/application.cpp`: девять генераторов при cells=16, complexity=2, конечность и диапазон плотностей, точный CSV roundtrip сферы, один повреждённый CSV.
- `apps/AnalyticModels.cpp`: sphere, torus, sphere-union, drilled-box, cone, gyroid, channels, lattice, shells. Область [-1,1]^3, n^3 ячеек, n=16..500, complexity=1..12. Ширина сглаживания 0.04; это не точные интегральные VF.
- `apps/main.cpp`: общий VF, прогрев, повторы, чередование порядка методов, медиана. Повторы сравниваются только по числам вершин/граней. CSV выводит секунды с тремя знаками после запятой.
- `data/models`: восемь PLY — Armadillo, bun_zipper, bun_zipper_closed, dragon_vrip, happy_vrip, PittsburghBridgeIsotropicClosed, spot_triangulated, spot_quadrangulated. Изучены заголовки; геометрическая корректность не проверена. Есть ASCII и оба бинарных порядка байтов.
- Оба Spot имеют 281428 байт, 2930 вершин и 5856 граней по заголовкам. Дублирование и степень граней не проверены.
- `data/models/README.md`: нет паспортов происхождения, хешей и ожидаемой топологии. В `data/volumes` при аудите только README, сохранённых VF нет.
- `docs/benchmark.md`: прежняя серия от 13 ноября 2026 отделена от текущей версии; исходные отчёты удалены пользователем. Старые замеры не подтверждают текущее прохождение тестов.

## 4. Принятые решения
Согласовано: аудит без изменения файлов; алгоритмы не подгонять; поддерживать только `.agents/testing.md`; относительные пути; никаких commit/push/pull без отдельного указания.
Предложения, не реализация: паспорта и хеши PLY, фиксированный банк VF, общие топологические метрики, независимые эталоны, серия разрешений с измерением памяти.

Изучены AGENTS, CMake/presets, шесть тестовых исходников, основной генератор, части CLI, документация benchmark и README банков. Инвентаризированы PLY и заголовки. Результаты аудита сообщены пользователю. Информации о задачах до этого чата нет.

## 6. Открытые вопросы и проблемы
- Текущее прохождение тестов неизвестно; запуск пока запрещён AGENTS.
- Нет зарегистрированных PLY-тестов и сквозных CLI-тестов PostTopOptRun.
- Нет общей проверки неманифолдности, вырожденности, ориентации, компонент и самопересечений для всех методов.
- Нет общего независимого контроля геометрической ошибки и объёма. Разделять ошибки PLY→VF и VF→поверхность.
- Не проверены лицензии/происхождение всех PLY, замкнутость и возможное дублирование Spot.
- Фиксированная физическая ширина сглаживания меняет число ячеек переходного слоя при смене разрешения.
- Переносимость случайных входов между стандартными библиотеками не исследована; seed сам по себе не гарантирует побитовое совпадение.
