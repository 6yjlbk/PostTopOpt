# Прежние программы

Здесь сохранены прямые аналитические примеры и специальные эксперименты. Основная программа запуска и сравнения — `PostTopOptRun` в `apps/main.cpp`. Актуальные команды и единый формат результатов описаны в [docs/running.md](../../docs/running.md).

Старые программы имеют собственные интерфейсы и не обязаны повторять настройки и формат нового CLI. Для воспроизводимого сравнения VF следует использовать новый CLI. Прямой аналитический API библиотеки сохранён.
